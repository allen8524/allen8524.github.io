개인프로젝트 · Laravel 2025.12

프로젝트 개요

Laravel 기반으로 제품·재고·판매 데이터를 연결해 관리 화면에서 흐름을 확인할 수 있도록 구성한 웹 프로젝트입니다. 제품 등록/수정, 재고 확인, 판매 내역 조회를 분리해 처리하고 일부 화면은 Ajax 갱신으로 필요한 데이터만 다시 조회하도록 정리했습니다.

Laravel Ajax 관리

개발 목적

이 프로젝트는 데이터 흐름을 이해하기 위해 구현한 관리형 웹 프로젝트로, 제품 데이터가 재고와 판매 조회에 어떻게 연결되는지 확인하는 데 목적을 두었습니다.

제품 등록/수정 화면, 재고 확인 화면, 판매 데이터 조회 화면을 구분해 구성하고, 관리자 기준에서 같은 제품 데이터가 화면별로 일관되게 보이도록 흐름을 정리했습니다.

일부 구간은 Ajax 비동기 요청으로 처리해 전체 새로고침 없이 변경된 값만 확인하도록 구성했고, 입력 검증 및 예외 응답 처리를 함께 점검했습니다.

핵심 구현 포인트

1) 제품·재고·판매 데이터 연결 구조

구현 포인트: 제품 중심 데이터를 재고와 판매 조회에 연결하는 구조를 정리했습니다.
처리 방식: 제품 등록/수정 시 저장한 값을 기준 데이터로 두고, 재고 상태와 판매 내역 조회에서 같은 제품 키를 사용하도록 맞췄습니다.
확인 가능한 결과: 제품 정보를 갱신한 뒤 재고·판매 화면에서 연관 데이터가 같은 기준으로 이어지는 흐름을 확인할 수 있습니다.

2) 관리자 판매/재고 흐름 확인 기능

구현 포인트: 관리자 화면에서 운영 데이터 확인 동선을 역할별로 나눴습니다.
처리 방식: 제품 관리, 재고 확인, 판매 조회 화면을 역할별로 나누고 테이블/목록에서 필요한 항목만 보이게 정리했습니다.
확인 가능한 결과: 관리자 화면에서 제품 상태 변경 후 재고 현황과 판매 내역을 순차 확인하는 흐름을 재현할 수 있습니다.

3) Ajax 비동기 처리와 입력/예외 검증

구현 포인트: 일부 화면에서 비동기 갱신과 예외 처리를 적용했습니다.
처리 방식: Ajax 요청으로 필요한 데이터 구간만 갱신하고, 입력값 검증 및 null/예외 응답을 화면에서 확인하도록 처리 흐름을 정리했습니다.
확인 가능한 결과: 데이터 변경 후 전체 페이지 이동 없이 조회 값이 갱신되고, 잘못된 입력 또는 누락 데이터 상황에서 예외 응답을 확인할 수 있습니다.

핵심 기능

1

제품 등록 및 분류

제품 정보를 카드형 UI와 목록으로 나눠 관리하고, 등록·수정 결과를 같은 화면에서 바로 확인하게 했습니다.

2

재고 확인 흐름

제품별 재고와 판매 흐름을 함께 확인할 수 있도록 조회 화면을 연결해 관리 기준이 한눈에 보이도록 정리했습니다.

3

매출 테이블 관리

판매 데이터와 매출 흐름을 표로 정리해 관리자 화면에서 변동 내역을 항목별로 빠르게 확인하게 했습니다.

4

일부 Ajax 갱신

일부 데이터는 비동기 갱신으로 처리해 화면 전환 없이 필요한 영역만 다시 조회하도록 했습니다.

사용 기술

Laravel 기반 CRUD와 데이터 조회 로직으로 제품, 재고, 판매 데이터를 연결하고 Bootstrap UI와 일부 Ajax 갱신으로 관리 화면의 확인 동선을 줄였습니다.

구현 확인 포인트

1) 관리자 화면 기준 확인

관련 화면: 제품 관리, 재고 관리, 판매 관리, 관리자 대시보드.
확인 방법: 제품 정보를 등록/수정한 뒤 재고/판매 화면에서 같은 제품 기준 데이터가 조회되는지 확인할 수 있습니다.

2) 관리자 중심 운영 흐름

핵심 흐름: 제품 등록 → 재고 수량 관리 → 판매 데이터 입력 또는 조회 → 관리자 화면에서 상태 확인.
확인 포인트: 특정 제품 상태를 관리자 화면에서 등록→재고→판매 순서로 추적할 수 있습니다.

3) 데이터 분리 관리

확인 포인트: 제품/재고/판매 데이터를 분리 관리하고 화면별로 필요한 데이터만 조회합니다.
검증 기준: 관리자 화면에서 영역별 데이터가 독립적으로 갱신되며 기본 연결 키를 통해 함께 확인되는 흐름입니다.
