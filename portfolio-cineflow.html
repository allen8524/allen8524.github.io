프로젝트 개요

Spring Boot 기반 영화 예매 프로젝트로, 영화 목록 조회부터 상영 일정 선택, 좌석 예매, 결제, 예매 취소, 관리자 CRUD까지 이어지는 흐름을 구현했습니다.

Spring Boot JPA Security Flyway

개발 목적

영화 예매 서비스의 핵심 흐름을 백엔드 중심으로 나누고, 공개 화면·회원 기능·관리자 기능의 접근 기준을 분리하는 데 목적을 두었습니다.

영화 선택, 상영 회차 선택, 좌석 선택, 결제, 예매 완료, 취소로 이어지는 상태 변화를 DB와 화면 흐름이 함께 따라가도록 구성했습니다.

핵심 구현 포인트

1) 예매 흐름 상태 관리

처리 방식: 영화 선택부터 결제 완료와 취소까지 단계별 URL과 데이터를 나누고, 예매 내역 조회에서 같은 예약 정보를 확인하도록 구성했습니다.

2) 회원·관리자 권한 분리

처리 방식: Spring Security 기준으로 공개 조회, 회원 예매, 관리자 CRUD 경로를 분리해 권한별 접근 범위를 명확히 했습니다.

3) Flyway 기반 DB 관리

처리 방식: 개발/로컬 환경 설정과 DB 마이그레이션 파일을 분리해 테이블 구조 변경 이력을 추적할 수 있게 했습니다.

영화 선택 → 극장/날짜/상영회차 선택 → 좌석 선택 → 결제 → 예매 완료 → 예매 내역/취소

확인 포인트

Spring Security로 공개/회원/관리자 경로를 분리하고, Flyway로 DB 마이그레이션 구조를 관리했습니다.
