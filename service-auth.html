회원 및 권한 관리

  1. 홈
  2. 회원 및 권한 관리

회원가입부터 관리자 접근 제어까지 인증/인가 흐름을 설계하고 적용했습니다

쇼핑몰 판매관리 프로젝트에서 로그인·로그아웃, 회원 정보 조회/수정, 세션 유지 흐름을 단계별로 나눠 적용했습니다. 사용자/관리자 분기를 두어 관리자 페이지 접근 제어와 인증 상태별 화면 처리를 분리한 내용을 중심으로 정리했습니다.

핵심 구현 내용

쇼핑몰 프로젝트에서 실제로 사용한 인증 로직을 기준으로 작성했습니다. 로그인 세션 확인, 사용자/관리자 권한 분기, 관리자 URL 접근 제어를 공통 조건으로 처리했습니다.

회원가입/로그인 흐름

쇼핑몰 판매관리 프로젝트에서 회원가입 입력 검증, 중복 계정 확인, 로그인 실패 메시지 처리를 적용했습니다. 로그인 성공 시 사용자 식별값을 세션에 저장해 이후 권한 분기와 화면 표시 기준으로 사용했습니다.

세션 처리 및 상태 유지

로그인 상태에서는 마이페이지·주문·장바구니로 이동하고, 세션이 없으면 로그인 페이지로 이동하도록 분기했습니다. 로그아웃 시 세션을 정리해 인증 상태 변경이 메뉴와 접근 제어에 즉시 반영되게 했습니다.

권한 분기와 관리자 접근 제어

사용자/관리자 권한을 분리해 상품·주문 관리 메뉴는 관리자 계정에만 노출했습니다. 관리자 URL 직접 접근 시에도 세션과 권한 값을 함께 검사해 우회 접근을 막았습니다.

문제 해결 경험

세션 만료 직후 이전 화면이 잠깐 보이던 문제를 재현해, 페이지 진입 시 공통 인증 체크를 먼저 수행하도록 실행 순서를 변경했습니다. 권한 분기 조건을 통일해 사용자 화면과 관리자 화면이 뒤섞이는 경우도 줄였습니다.

인증/인가 구현 포인트

01

요구사항 분리

회원 기능과 관리자 기능을 먼저 분리하고, 각 화면에서 필요한 권한 범위를 명확히 정의했습니다.

02

세션 기준 설계

로그인 유지 기준, 만료 처리, 로그아웃 동작을 먼저 설계해 상태 꼬임을 줄였습니다.

03

권한 체크 공통화

페이지 단위로 권한 확인 로직을 통일해 우회 접근과 중복 코드를 함께 줄였습니다.

04

예외 흐름 검증

로그인 실패, 세션 만료, 비정상 접근 시 메시지와 이동 경로를 점검하며 안정성을 보완했습니다.

프로젝트 적용 근거

적용 프로젝트

쇼핑몰 판매관리 사이트를 중심으로 로그인/회원 세션 흐름을 연결했고, e스포츠 포털과 베이커리 프로젝트에서는 관리자 화면 접근 분기 기준을 같은 방식으로 적용했습니다.

관련 기능 화면

로그인, 회원가입, 마이페이지, 관리자 로그인, 관리자 관리 화면을 기준으로 비로그인 접근 제한과 관리자 전용 메뉴 노출 조건을 분리했습니다.

관련 코드/DB 근거

쇼핑몰 기준 관련 파일: member_login.php, member_logout.php, admin/login.php, admin/check.php
세션 키: $_SESSION["member_id"], $_SESSION["member_name"], $_SESSION["admin_id"]
권한 기준: 사용자 기능은 회원 세션 기준으로 처리하고, 관리자 URL은 admin/check.php에서 관리자 세션 존재 여부를 먼저 확인했습니다.
Laravel 기준 관련 위치: routes/web.php, Auth 관련 컨트롤러, 관리자 미들웨어, 관리자 전용 라우트 그룹

주 사용 기술

  • 인증 처리: PHP 세션 기반 로그인 상태 확인
  • 권한 분기: 사용자/관리자 화면 분리와 메뉴 제어
  • 접근 제어: 관리자 URL 진입 시 권한 검사
  • 프레임워크 이해: Laravel 인증 흐름과 미들웨어 구조

구현 포인트

  • 회원가입: 중복 검사, 필수값 검증, 실패 메시지 처리
  • 로그인/세션: 세션 저장, 유지, 로그아웃 정리
  • 권한 분기: 사용자/관리자 메뉴 및 기능 분리
  • 접근 제어: 관리자 URL 직접 접근 차단 로직 적용

관련 프로젝트 연결

  • 쇼핑몰 판매관리 사이트: 로그인/로그아웃, 세션 유지, 회원 정보 처리와 주문 화면 접근 제어를 연결해 구현한 근거입니다.
  • 베이커리 판매관리 웹사이트: 관리자 계정 기준으로 제품·재고 관리 메뉴 접근을 분리해 권한 제어 흐름을 확인할 수 있습니다.
  • e스포츠 포털 및 경기관리 웹사이트: 공개 조회 화면과 관리 기능 화면을 분리해 인증 상태별 화면 구성을 보완한 프로젝트입니다.

사용 기술

  • 쇼핑몰 프로젝트 기준 세션 저장/만료/로그아웃 처리
  • 관리자 기능 진입 전 공통 권한 체크 로직 정리
  • 인증 상태에 따라 사용자 화면과 관리자 화면 분리
