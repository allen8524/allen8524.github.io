기타 프로젝트 · iOS 2026

프로젝트 개요

UIKit과 Storyboard로 제작한 iOS 건강관리 앱입니다. BMI 계산 결과를 기준으로 상태 문구와 UI 피드백을 표시하고, 운동 정보 탐색·운동 영상·운동 계획 화면으로 이어지는 탭 구조를 구성했습니다.

Swift UIKit Storyboard WebKit

개발 목적

BMI 계산 결과를 사용자에게 직관적으로 보여주고, 운동 정보 탐색과 영상 재생, 계획 설정 화면으로 자연스럽게 이동하는 건강관리 앱 흐름을 구성했습니다.

입력값 검증과 성별 기준 분기를 통해 결과 문구와 UI 피드백이 상황에 맞게 표시되도록 했습니다.

핵심 구현 포인트

1) BMI 계산과 검증

처리 방식: 키와 몸무게 입력값을 검증하고 성별 기준에 따라 BMI 상태 문구와 화면 피드백을 다르게 표시했습니다.

2) 운동 정보 탐색

처리 방식: WebKit 기반 운동 정보 화면을 구성해 앱 내부에서 관련 정보를 탐색할 수 있도록 했습니다.

3) 영상과 계획 화면

처리 방식: AVKit 영상 재생 화면과 운동 계획 설정 화면을 탭 구조로 연결해 사용자가 결과 이후 행동을 이어갈 수 있게 했습니다.

BMI 입력 → 입력값 검증 → 성별 기준 BMI 판정 → 결과 UI 피드백 → 운동 정보/영상/계획 화면 이동
