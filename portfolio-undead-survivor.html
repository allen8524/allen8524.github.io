프로젝트 개요

Unity와 C#으로 제작한 Android 기반 생존형 액션 게임입니다. 플레이어 이동, 자동 공격, 적 스폰, 오브젝트 풀링, 레벨업 보상, 결과 화면까지 이어지는 게임 루프를 구현했습니다.

Unity C# Android Object Pooling

개발 목적

모바일 환경에서 반복 생성되는 적과 투사체를 효율적으로 관리하고, 생존형 액션 게임의 기본 루프를 끝까지 구현하는 데 목적을 두었습니다.

캐릭터 선택 이후 이동, 자동 공격, 적 스폰, 경험치 획득, 레벨업 보상, 생존/사망 결과 처리까지 한 흐름으로 연결했습니다.

핵심 구현 포인트

1) 게임 루프 구성

처리 방식: 캐릭터 선택 후 플레이어 입력, 자동 공격, 적 스폰이 동시에 진행되도록 게임 매니저 중심 흐름을 구성했습니다.

2) 오브젝트 풀링

처리 방식: 반복 생성되는 적과 공격 오브젝트를 풀로 관리해 모바일 실행 환경에서 생성/삭제 부담을 줄였습니다.

3) 레벨업과 결과 처리

처리 방식: 경험치 획득 후 레벨업 보상을 선택하고, 생존 또는 사망 상태에 따라 결과 화면으로 이어지게 했습니다.
