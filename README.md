# 황민서 포트폴리오 사이트

GitHub Pages로 배포하는 개인 개발자 포트폴리오 사이트입니다.

Spring Boot, Laravel, PHP 기반 백엔드 웹 프로젝트를 중심으로 데이터 분석, iOS 앱, Unity 게임 프로젝트까지 한곳에서 확인할 수 있도록 구성했습니다. 단순 자기소개 페이지가 아니라 프로젝트별 구현 근거, 사용 기술, 상세 페이지, 개발 역량, 트러블슈팅 사례, 연락처를 연결한 정적 포트폴리오 웹사이트입니다.

## 포트폴리오 방향

이 사이트는 프로젝트 개수만 나열하는 방식이 아니라, 각 프로젝트에서 실제로 어떤 기능을 구현했고 어떤 데이터 흐름을 다뤘는지 보여주는 데 초점을 둡니다.

주요 구성 방향은 다음과 같습니다.

| 구분 | 설명 |
| --- | --- |
| 백엔드 중심성 | 예매, 주문, 게시판, 관리자 기능처럼 서버 로직과 DB 연동이 필요한 기능을 중심으로 설명 |
| 구현 근거 | 프로젝트 상세 페이지에서 관련 파일, 처리 흐름, DB 구조, 상태 관리 기준을 함께 제시 |
| 프로젝트 확장성 | 웹 프로젝트 외에도 데이터 분석, iOS 앱, Unity 게임 프로젝트를 확장 경험으로 정리 |
| 면접 대응 | 단순 결과물보다 구현 과정, 문제 해결, 데이터 흐름, 권한 분리, 상태 관리를 강조 |
| 정적 배포 | GitHub Pages에서 별도 서버 없이 바로 확인할 수 있도록 구성 |

## 프로젝트 상세 페이지 구성

각 프로젝트 상세 페이지는 공통적으로 다음 흐름을 가집니다.

```text
프로젝트 개요
→ 개발 목적
→ 프로젝트 스펙
→ 핵심 구현 포인트
→ 핵심 기능
→ 사용 기술
→ 내가 구현한 부분
→ 구현 확인 포인트
→ 이미지 미리보기
→ GitHub 링크
```

이 구조를 사용해 면접관이 다음 정보를 빠르게 확인할 수 있도록 했습니다.

| 확인 항목 | 설명 |
| --- | --- |
| 무엇을 만들었는가 | 프로젝트 개요와 한줄 소개 |
| 어떤 기술을 썼는가 | 사용 기술과 프로젝트 태그 |
| 어떤 부분을 구현했는가 | 내가 구현한 부분, 핵심 구현 포인트 |
| 실제 근거가 있는가 | 관련 파일, DB 흐름, 화면 이미지, GitHub 링크 |
| 어떤 문제를 해결했는가 | 트러블슈팅 및 구현 확인 포인트 |
