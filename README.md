# 황민서 백엔드 포트폴리오 사이트

이 저장소는 **개인 백엔드 개발자 포트폴리오 사이트**를 관리하는 GitHub Pages 저장소입니다. PHP, Laravel, MySQL/MariaDB 기반 웹 프로젝트를 중심으로 관리자 기능, 주문 흐름, 콘텐츠 관리, DB 연동 경험을 정리했습니다.

- 배포 주소: https://allen8524.github.io/
- GitHub Pages로 정적 포트폴리오 사이트를 운영합니다.

## 대표 프로젝트

### 1) 쇼핑몰 판매관리 사이트
- 목적: 상품 조회부터 주문 처리, 관리자 관리 흐름까지 하나의 쇼핑몰 프로세스로 구현
- 주요 기능: 상품 목록/검색, 장바구니, 주문 저장, 관리자 상품·주문 관리, 회원/관리자 분기
- 사용 기술: PHP, Bootstrap, MariaDB
- 링크:
  - 상세 페이지: https://allen8524.github.io/portfolio-details.html
  - GitHub: https://github.com/allen8524/shopping-mall-management-php

### 2) e스포츠 포털 관리 사이트
- 목적: 경기 정보와 콘텐츠를 관리자 화면에서 등록하고 사용자 화면에서 조회 가능한 구조 구현
- 주요 기능: 팀/선수/경기 일정·결과 관리, 순위 반영, 뉴스/공지/패치노트 관리
- 사용 기술: Laravel, Bootstrap, MySQL
- 링크:
  - 상세 페이지: https://allen8524.github.io/portfolio-esports.html
  - GitHub: https://github.com/allen8524/esports-portal-management

### 3) 베이커리 판매관리 사이트
- 목적: 제품·재고·판매 데이터를 연결해 매장 운영 데이터를 관리하는 흐름 구현
- 주요 기능: 제품/재고/판매 관리, 관리자 화면 데이터 조회, 일부 화면 Ajax 갱신
- 사용 기술: Laravel, Bootstrap, MySQL
- 링크:
  - 상세 페이지: https://allen8524.github.io/portfolio-bakery.html
  - GitHub: https://github.com/allen8524/bakery-sales-management-laravel

## 기술 스택

- Frontend: HTML, CSS, JavaScript, Bootstrap
- Backend: PHP, Laravel
- Database: MySQL, MariaDB
- Tools: Git, GitHub, VS Code
- Deployment: GitHub Pages

## 저장소 구조

- `index.html`: 메인 포트폴리오 페이지
- `portfolio-*.html`: 프로젝트 상세 페이지
- `service-*.html`: 개발 역량 상세 페이지
- `assets/css/`: 스타일 파일
- `assets/js/`: 스크립트 파일
- `assets/img/`: 이미지 리소스
- `assets/files/`: 이력서 등 다운로드 파일

## 문서/콘텐츠 관리 기준

- 디자인 변경과 콘텐츠 수정 작업을 분리해 관리합니다.
- CSS 변경은 `assets/css/main.css` 중심으로 관리합니다.
- 이미지/파일 경로를 변경할 때는 관련 링크와 미리보기 동작을 함께 확인합니다.
- 프로젝트를 추가/수정할 때는 메인 카드, 상세 페이지, README를 함께 갱신합니다.
