게시판 및 콘텐츠

  1. 홈
  2. 게시판 및 콘텐츠

사용자 화면과 운영 화면을 함께 고려해 게시판 기능을 구현했습니다

e스포츠 포털 및 경기관리 웹사이트에서 뉴스·공지·패치노트와 팀/선수/경기 데이터를 관리자 등록과 사용자 조회 흐름으로 나눠 적용했습니다. 검색·정렬·페이징·이미지 업로드를 포함해 콘텐츠 관리 기능을 화면별로 구현했습니다.

핵심 구현 내용

단순 게시판 CRUD를 넘어 콘텐츠 등록과 사용자 조회 기능을 분리 구현했습니다. 관리자 입력 데이터가 목록·상세·랭킹 화면에 어떤 조건으로 노출되는지 프로젝트 구조에 맞춰 맞췄습니다.

게시판 CRUD

e스포츠 포털에서 뉴스·공지·패치노트 등록/수정/삭제와 상세 조회를 적용했습니다. 콘텐츠 유형별 입력값 검증을 두어 관리자 작성 데이터가 사용자 화면에 안정적으로 노출되게 했습니다.

목록, 검색, 정렬, 페이징

콘텐츠 목록과 팀/선수/경기 일정 화면에 검색·정렬·페이징 조건을 분리 적용했습니다. 최신순/조건별 정렬과 빈 결과 안내를 함께 처리해 탐색 흐름이 끊기지 않게 했습니다.

콘텐츠 관리 및 첨부 흐름

관리자 화면에서 콘텐츠 등록 시 대표 이미지와 본문 데이터를 함께 저장하도록 처리했습니다. 업로드 확장자와 필수 입력을 점검해 잘못된 파일이 사용자 화면에 노출되지 않게 했습니다.

문제 해결 경험

관리자에서 수정한 콘텐츠가 사용자 목록에 즉시 반영되지 않던 문제를 조회 조건과 정렬 쿼리를 점검해 해결했습니다. 경기 일정 페이지의 페이징/필터 동작도 분리해 검색 조건이 유지되도록 개선했습니다.

게시판 구현 포인트

01

정보 구조 설계

카테고리, 목록, 상세 화면의 이동 흐름을 먼저 설계했습니다.

02

CRUD 기능 구현

작성·수정·삭제·조회 기능을 권한 조건별로 나눠 적용했습니다.

03

검색/페이징 최적화

목록 탐색 편의성을 위해 검색 조건과 페이지 이동 로직을 분리 구현했습니다.

04

운영 기능 보완

관리자 콘텐츠 관리와 첨부 처리 검증으로 운영 안정성을 높였습니다.

프로젝트 적용 근거

적용 프로젝트

e스포츠 포털에서는 뉴스/패치노트/공지 흐름을 중심으로 적용했고, 쇼핑몰에서는 FAQ·공지성 콘텐츠가 운영 화면과 사용자 조회 화면에서 같은 기준으로 보이게 맞췄습니다.

관련 기능 화면

게시글 목록, 게시글 상세, 작성/수정/삭제, FAQ/공지 관리 화면을 분리했습니다. 관리자 입력 데이터가 사용자 화면에서 어떤 형태로 노출되는지 화면 단위로 확인할 수 있습니다.

관련 코드/DB 근거

Laravel 기준 관련 위치: routes/web.php, NewsController, resources/views/news, resources/views/admin/news
조회 기준: 목록은 검색 조건과 페이지 번호를 함께 유지하고, 상세는 slug 기준으로 단건 조회
관리자 처리: 관리자 화면에서 뉴스/공지 등록·수정·삭제를 분리하고 사용자 화면은 공개된 콘텐츠만 노출
이미지 처리: 업로드 확장자와 저장 경로를 분리해 콘텐츠 데이터와 함께 관리했습니다.

주 사용 기술

  • 백엔드: Laravel, Blade, MySQL
  • 콘텐츠 처리: CRUD 기반 뉴스·공지·패치노트 관리
  • 목록 기능: 검색·정렬·페이징 조건 분리
  • 미디어: 이미지 업로드 검증 및 저장

구현 포인트

  • 콘텐츠 관리: 뉴스·공지·패치노트 등록/수정/삭제 및 노출 제어
  • 정보 데이터: 팀/선수 데이터와 경기 일정·결과 화면 연동
  • 탐색 기능: 검색·정렬·페이징 조합으로 목록 접근성 개선
  • 첨부 처리: 이미지 업로드 검증 후 콘텐츠와 함께 저장

관련 프로젝트 연결

  • e스포츠 포털 및 경기관리 웹사이트: 관리자 콘텐츠 등록이 사용자 뉴스/공지/패치노트 및 경기 정보 화면으로 연결되는 핵심 근거입니다.
  • 쇼핑몰 판매관리 사이트: 공지성 게시판과 사용자 조회 흐름을 구현해 콘텐츠 노출 구조를 확장한 경험입니다.
  • 개발 블로그: 게시판 기능 구현 및 오류 해결 기록 정리

사용 기술

  • e스포츠 포털 및 경기관리 웹사이트에서 관리자 등록 콘텐츠를 사용자 화면 조회로 연결
  • 뉴스·패치노트·팀/선수·경기 일정 데이터를 화면별로 분리 조회
  • 검색·정렬·페이징을 조합해 목록 탐색 흐름 구성
